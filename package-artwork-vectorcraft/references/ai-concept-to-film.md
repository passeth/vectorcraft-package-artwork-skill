# 생성 AI 시안 → 인쇄용 필름

디자이너 필름이 없고 **생성 AI가 만든 시안 이미지**(목업·렌더)만 있을 때의 절차. 시범: 120ml
원형 튜브(Ø40) 클렌징 폼 — AI 시안 이미지, 전성분 docx, 규격 "120ml 원형 튜브 40Ø"만으로 별색 3도 튜브 필름을 만들었다.
결과는 **최종 필름 직전의 초안**이다. 규격·색·법규 확정은 담당자가 한다(아래 "사람이 정할 것").

## 입력 받기

- 시안 이미지가 파일로 없고 채팅에 붙여 넣었다면, 사용자에게 파일 저장을 요청한다. macOS에서 클립보드에 그림이 남아 있으면
  먼저 `osascript -e 'clipboard info'`로 **종류만** 확인하고, 그림(PNGf)일 때만 PNG로 저장한다. 그렇게 했다고 사용자에게 알린다.
- 시안에 여러 제품이 있으면 어느 것인지 정한다(전성분·제품명으로 판단 가능하면 그렇게 하고 알린다).
- 규격: 용기 종류·지름·용량. 튜브 길이·실링부·아이마크 규격은 대개 빠져 있다 → 시안 비율로 역산한 값을 가정으로 쓰고 표시한다.
- 전성분 원문(docx 등)과 제품 코드·Lab no.가 있으면 함께 받는다. 사내 제품 DB가 있으면 같은 브랜드·라인의 기존 제품명 표기를 찾아 맞춘다.

## 튜브: 시안을 펼친 필름 좌표로

`scripts/tube_unwrap.py`
- 필름 = 둘레(πD) × 길이, 앞면·뒷면 각 πD/2 (Ø40 → 125.66 × L, 패널 62.83 mm).
- 채워진 튜브는 크림프에서 납작하고 어깨에서 둥글다. 높이마다 단면을 "앞쪽 반둘레 = πD/2인 타원"으로 보고 보이는 가로 위치를 호 길이로 바꾼다.
  가장자리는 패널 끝, 둥근 부분의 가운데 내용은 실제 크기로 옮겨진다. 보이는 폭을 패널 폭에 직선으로 늘리면 어깨 쪽 글자가 최대 1.57배 커진다(시범에서 실제로 발생).
- 확인: `tube_unwrap.py <시안> <D> <L> --sample X Y --x-range …` → 어깨/크림프 폭 비(실물 0.64), 크림프 폭으로 역산한 길이.
  배경색이 몸통색과 비슷하면 감지가 이미지 끝까지 번진다(경고) → `--tol`을 낮추거나 범위를 좁힌다. 시범: 몸통 1165 px, 크림프 폭으로 역산한 길이 ≈ 148 mm.
- 다른 용기(원형 병 용기인쇄 등)는 원통 투영(호 길이 = R·asin(x/R))으로 같은 방식으로 펼친다.

## 무엇을 따내고 무엇을 다시 만들까

| 요소 | 방법 | 이유 |
|---|---|---|
| 큰 글자·문구 | **실제 서체로 다시 조판** (`Doc.fit_text`, 초압축 대형 글자는 `Doc.stretch_word`: 폭을 100%로 맞춘 뒤 세로 확대) | AI 글자는 모양이 불규칙하고, 스티커 등에 가려진 부분은 복원할 수 없다 |
| 스티커·배지 같은 단순 도형 | **수식으로 생성** (`Doc.wavy_badge` 등) | 트레이스하면 가장자리가 거칠다(시범에서 확인 후 교체) |
| 복잡한 일러스트·심볼 | 트레이스(Logo 모드)로 초안, "원본 교체 필요" 표시 | 원본 벡터가 없을 때만 |
| 로고 | 원본 파일을 받는다. 없으면 텍스트·트레이스로 대체하고 표시 | 브랜드 자산 |

- 펼친 필름에서 디자인을 다듬는다(예: 둥근 단면 때문에 시안에서 양끝까지 닿는 단어는 펼치면 여백이 1~2 mm라 위 단어 폭에 맞춰 통일). 바꾼 것은 보고서에 적는다.
- 색: 시안의 평평하게 밝은 곳에서 중앙값으로 잰다(그림자·하이라이트 제외). **VectorCraft에는 PANTONE 라이브러리가 없다** → 번호를 지어내지 않는다.
  역할 이름의 별색(예: `SPOT 1 크림 바탕`)과 측정값을 남기고 PANTONE 지정을 요청한다. CMYK 색역 밖 색(시범의 라벤더)은 문서에서 다른 값으로 보이니 별색 필수라고 적는다.

## 뒷면·표시사항 (시안에 없을 때)

- 같은 서체·색 체계로 새로 짠다: 브랜드 → 제품명(국·영) → 특장점 → 사용법 → 전성분 → 주의사항 → 소비자 상담실 → 제조업자·사용기한·용량·원산지.
- **특장점은 전성분에서 근거를 찾아** 쓴다. 성분 DB(사내 DB나 공개 성분 사전)로 기능·분류를 확인하고, 문구마다 근거 성분을 보고서 표로 남긴다.
  함량 표시는 원문에 있는 값만 쓴다(예: 원문에 "○○추출물(10,000 ppm)"처럼 적힌 값). 처방과 맞지 않는 주장은 넣지 않는다(시범: 비누계 처방 → "약산성" 제외).
- 문단은 디자이너 줄바꿈이 없으므로 `Doc.paragraph_auto`(폭을 재서 줄바꿈, 줄머리 문장부호 금지, 마지막 줄만 왼쪽 정렬)를 쓴다.
  공간이 남으면 본문을 키운다(시범 5.5 → 6.5 pt). 전성분은 줄을 이어 붙여 원문과 같은지 확인한다.
- 바코드 번호·분리배출 표시(재질)·PAO처럼 정보가 없는 것은 **비인쇄 가이드 레이어에 자리 표시**(`Doc.placeholder`)만 한다.
- 가이드 레이어(실링선·접는 선·어깨 안전선·자리 표시)는 **마지막에 맨 위로 올린다**(`Doc.raise_layer`). `layer.new {top:true}`는 새 레이어를 계속 위에 쌓아서, 일찍 만든 가이드가 바탕 아래에 깔린다.

## 확인

- 판 레이어마다 칠이 해당 별색뿐인지 센다.
- 인쇄용 PDF: `verify_print_pdf.py --expect-spots "…"`(폰트 0·텍스트 0·이미지 0). 가이드는 PDF에서 빠지지만 **PNG 내보내기에는 그려진다** → 검토용 PNG와 인쇄 PDF를 구분하고, PDF 렌더에 가이드 색 픽셀이 없는지 확인한다.
- 시안 대비 이미지(시안 튜브 | 필름 앞면)를 결과물에 넣는다.

## 사람이 정할 것 (보고서에 반드시 남김)

PANTONE 지정 · 튜브/용기 업체 도면(길이·실링부·아이마크·인쇄 가능 영역) · 실링부 바탕 인쇄 여부 · 바코드 번호 · 재질(분리배출) · 제품명·책임판매업자 확정 ·
특장점·주의사항 표시광고 검토 · 서체 라이선스(상업 인쇄)·브랜드 서체 · 로고 원본.
